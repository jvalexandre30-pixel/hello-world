# Hello World em HTML

Este é um projeto extremamente simples criado para demonstrar a estrutura básica de uma página web utilizando HTML5. É o ponto de partida ideal para quem está começando a aprender desenvolvimento web.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estruturação do conteúdo da página.

## 💻 Como Executar o Projeto

Você não precisa instalar nenhum servidor ou dependência externa para rodar este projeto. Basta ter um navegador de internet instalado no seu computador.

### Passo a Passo:

1. **Clone ou baixe** este repositório.
2. Navegue até a pasta do projeto.
3. Dê dois cliques no arquivo `index.html`.
4. O projeto abrirá automaticamente no seu navegador padrão exibindo a mensagem "Hello, World!".

## 📂 Estrutura do Código

O arquivo principal `index.html` contém as seguintes marcações essenciais:

* `<!DOCTYPE html>`: Define que o documento utiliza a versão mais recente do HTML (HTML5).
* `<html lang="pt-BR">`: Tag raiz que envolve todo o conteúdo e define o idioma da página.
* `<head>`: Contém os metadados da página, como a codificação de caracteres (`UTF-8`) e o título da aba do navegador.
* `<body>`: O corpo da página, onde fica o conteúdo visível. No caso, uma tag `<h1>` para o título principal.
